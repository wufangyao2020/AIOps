# A 股 2026 年中报全量扫描档案

本仓库用于归档 **2026 年半年报季全部 A 股公司母池**，并为后续四模型盲扫提供可复现的数据入口。

## 当前版本状态

- 报告期：`2026H1`
- 公开统计口径：5550 家 A 股公司
- 当前阶段：`Stage 0 — raw universe archive`
- 已完成：全量母池抓取脚本、标准化字段定义、交易所拆分规则、研究状态表结构、校验规则
- 自动生成中：5550 家母池 CSV / JSONL、交易所拆分文件、研究状态快照、校验摘要
- 未完成：基本面加速评分、新利润池评分、周期拐点评分、资本事件评分、前 100 家公告复核、同行比较、最终 20 只候选

## 数据来源与边界

母池通过东方财富数据中心公开接口抓取，正式公告仍以沪深北交易所及上市公司法定披露文件为准。公开报道显示，2026 年半年报季共有 5550 家 A 股公司披露报告。

数据页：`https://data.eastmoney.com/bbsj/202606/yjbb.html`

## 自动更新

GitHub Actions 每周一自动刷新，也支持手动运行。工作流会：

1. 拉取完整母池；
2. 去重并过滤 A 股；
3. 生成 CSV / JSONL；
4. 校验代码、重复项和数量；
5. 提交快照与校验元数据。

## 研究纪律

本仓库不把历史聊天频次作为候选生成信号。任何曾经讨论过的股票，都必须重新参加全市场横向竞争。
